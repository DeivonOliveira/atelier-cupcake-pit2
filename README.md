# Atelier Cupcake Gourmet

Aplicação web completa em Python (Flask + SQLite + Tailwind CSS) no padrão MVC com imagens reais integradas, carrinho interativo, cálculo de CEP, autenticação de clientes, painel administrativo e suíte de testes Pytest.

## Como Executar Localmente (Windows PowerShell / Linux)

```powershell
pip install -r requirements.txt
pytest -v
python app.py
```

Acesse `http://127.0.0.1:5000` no navegador.
